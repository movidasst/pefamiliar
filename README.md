# Plan Familiar de Emergencia

Aplicación web/PWA de **La Movida SST Plus** para construir, revisar y practicar un Plan Familiar de Emergencia.

- Sitio: https://pefamiliar.movidasst.com
- Enfoque mobile-first y offline.
- Los datos del plan se guardan localmente en el dispositivo.
- Sin Gemini ni APIs externas de amenazas.
- Incluye familia, amenazas y decisiones, zonas y puntos de encuentro, vivienda/plano, reunificación, roles, comunicación, kit, simulacros, respaldo y PDF.

## Producción

La versión publicada corresponde a la línea 2.1, con correcciones de persistencia, validación de completitud del kit y conservación de cambios al gestionar contactos.

El archivo `CNAME` debe conservarse para mantener el dominio personalizado de GitHub Pages.
